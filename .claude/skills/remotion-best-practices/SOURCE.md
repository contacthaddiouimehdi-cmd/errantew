# Source

Official Remotion agent skill, copied from https://github.com/remotion-dev/skills
(`skills/remotion-best-practices`, commit 039e8a2, 2026-10-19), reviewed before install:
documentation and example code only, no hooks, nothing that runs on its own. The two
map-prep scripts (`remotion-maps/.../prep-*.mjs`) only run if called by hand.

Found via the catalogue https://github.com/zhuyansen/awesome-claude-video-skills
(graded "safe", tested end to end there).

For this film, the brief and the Orange video guidelines take precedence over the
skill's defaults: previews are rendered at each checkpoint, and no map of Morocco is used.
